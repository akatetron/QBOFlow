      Why is this private?

      The page reads your file with the browser's FileReader API and builds the .QBO with JavaScript. There is no server endpoint to send data to. Disconnect from the internet after the page loads and it still works.

      How do I import?

      QuickBooks Desktop: File → Utilities → Import → Web Connect Files. QuickBooks Online: Banking → Upload transactions → select the .QBO file.

      Duplicate-safe

      Each transaction gets a stable ID derived from its date, amount and payee, so re-importing an overlapping statement won't create duplicates.
